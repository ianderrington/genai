# Tools

An agent's tools are the interfaces between a model and everything outside its own context window: external data, other services, actions in the real world. Without tools, a model can only generate text based on what's already in its prompt.

The dominant standard for connecting a model to tools today is the [Model Context Protocol](mcps.md), covered in depth on the next page, along with a curated list of MCP servers, bundlers, and integrations.
