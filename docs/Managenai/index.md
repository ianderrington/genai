## What ManaGen AI is

ManaGen AI is a living reference site for understanding, building, and using generative AI, covering everything from how a transformer works to how to run an agent in production to how to think about AI policy at your company. The goal is a single place you can point someone at, whatever level they're starting from.

## Who runs it

ManaGen AI is built and managed by [SI 42](https://si42.ai).

## How the content gets written

Most pages start from a mix of primary sources (papers, official docs, vendor announcements) and are drafted with AI assistance, then reviewed and edited by a human before publishing. Every factual claim on a reference or blog page should trace back to a real, checkable source, most pages link to their sources directly at the bottom. If you find a page that doesn't meet that bar, we want to know: see [Contributing](./contributing.md).

## Who it's for

The reference material spans beginner explanations through practitioner-level detail (frameworks, agent architectures, deployment tradeoffs). If you're new to the space, start with [Understanding GenAI](../Understanding/index.md); if you already work in AI, the [Using](../Using/index.md) section covers building and managing it in production.

## Help improve it

This is an evolving project, not a finished reference. If something is wrong, out of date, or missing, [contributing](./contributing.md) is the fastest way to fix it.
