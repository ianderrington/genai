
### Robotics

- [CLAIRIFY](https://ac-rad.github.io/clairify/) — translates natural-language instructions into domain-specific robot control languages. [Paper](https://arxiv.org/pdf/2303.14100.pdf)
- [RT-2](https://robotics-transformer2.github.io/assets/rt2.pdf) — a vision-language-action model built by fine-tuning a vision-language model (a PaLI-X or a PaLM-E variant) to output robot actions as text tokens, transferring web-scale visual and language knowledge directly into robot control.
