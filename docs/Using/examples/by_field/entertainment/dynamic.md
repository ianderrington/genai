# Movies and Video

- [Runway](https://runwayml.com/) — the strongest pick when video editing matters as much as generation; a real timeline-based editing interface alongside the Gen-4 model, not just a prompt box.
- [Kling](https://klingai.com/) — strong at high-motion, cinematic text-to-video scenes.
- [Luma Dream Machine](https://lumalabs.ai/dream-machine) — the value pick for image-to-video work, generally respecting real-world physics without enterprise pricing.
- [Pika](https://pika.art/) — the fastest iteration cycle of the group: cheap, quick experiments, weaker at long-form realism than the others above.

No single tool dominates every use case here — the four above trade off editing control, motion quality, physical realism, and iteration speed differently enough that which one fits depends on the specific shot you're trying to produce.
